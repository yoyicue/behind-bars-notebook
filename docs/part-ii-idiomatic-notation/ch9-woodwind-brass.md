# Chapter 9：木管与铜管（Woodwind and Brass）

## 9.1 通用规则（General topics）

- 总原则：**精确表达音乐意图，但不过度规定技术手段**——乐器构造不断改良，演奏者总能找到发出所需声音的办法；
- 非常规技法可以用**常规记谱 + 文字说明**来描述。

### 吐字与连奏（Articulation）

- 管乐演奏者默认对每个音单独吐字（articulate），除非标有连奏弧（slur）；
- 连奏弧表示音与音之间**完全的 legato**；弧内若带奏法记号（如 tenuto、staccato），则各音仍有独立起音，只是分离程度被连奏弧减弱；
- **木管**：同音反复（reiterated pitch）上只画连奏弧、不加奏法记号是"不合语法"的——每个音都必须吐字，应在弧下加 tenuto 线或 staccato 点，或改用文字 `legato`；

![连奏弧下的同音反复须加奏法记号（原书 p.245）](/img/ch09/articulation-slurs.png)

- **铜管**：同音反复上的连奏弧表示 legato tonguing（不必额外加记号）。

### 乐句划分（Phrasing）

- 管乐谱中**最好省略乐句线**，让连奏弧专门承担 legato 奏法功能；
- 两套弧线（乐句线 + 连奏弧）并存会让演奏者无法判断各自作用；
- 确需显示乐句结构时可用**虚线乐句弧**，但不推荐（视觉复杂、含义易被质疑）。

### 换气记号（Breath marks）

- `«` 记号置于谱表上方，**只用于明确要求声音中断处**；其余换气交给演奏者自行处理；
- 不要用乐句线表示"一口气奏完"——演奏者可能因技术原因须在别处换气；
- 休止符常是乐句的一部分，不必然表示换气；
- **换气占用的时间从前一个音里扣除**；
- 逗号（′）保留给乐句内的短顿或提起（lift），不要与换气记号混用。

![换气记号 «（原书 p.246）](/img/ch09/breath-marks.png)

### 吐字方式（Tonguing）

- 不必指定单吐/双吐/三吐，演奏者会按语境自行选择；
- 双吐、三吐可用文字要求（double-/triple-tonguing），但属技术层面，对声音无实质影响；如需描述质感可用 `soft-tongued`、`hard-edged attack` 等文字。

### 颤舌（Flutter-tonguing）

- 记法：**写成 tremolo（符杠上的斜线），谱表上方加缩写** `flt.` / `frull.`（意大利 frullo）/ `flz.`（德语 Flatterzunge）；
- 文字指示不可省略，否则 tremolo 会被误读为极快的节奏性吐字；
- 只有当颤舌的连音线延音转为普通持续音时才需取消，此时在普通音上方加 `ord.`（ordinario）提示变化；

![颤舌记法：tremolo 加 flz. 文字（原书 p.247）](/img/ch09/flutter-tonguing.png)

### 微分音（Microtones）

- 管乐微分音靠唇/口型调整或特殊指法实现，演奏者会自行选择方式；
- 一般按**音乐语境**拼写微分音；若需演奏者从某音上/下弯至目标音，则**按其接近方向记谱**（如需降低的音，用带向下箭头的微分记号从半音音高出发）。

### 滑音（Glissandos）

- **常规滑音**：两外音之间斜线 + `gliss.`，表示尽可能连续的滑动；
- **quasi gliss.**：完全平滑的滑音技术上不可能时，把半音阶写全并配此指示；
- **pitch bend（唇滑音）**：靠口型/喉部改变音高，记为**符头后的一条线**（可弯成滑音轮廓），可标 `lip` 或 `bend`，强调不是逐个半音指法；

![pitch bend：符头后的滑线（原书 p.248）](/img/ch09/pitch-bend.png)

- **chromatic gliss.**：由半音阶构成的滑音应把半音写全（按实际时值或倚音），加 `chromatic`（缩写 chrom.）指示，防止演奏者直接滑过去。

### 特殊技法记谱原则（Special techniques）

- 特殊技法可用**异形符头**区分于普通音符，但必须有文字限定；
- **一种异形符头在一首作品中只应有一个含义**；多种技法交替时可用彼此对比的符头形状；
- **无音高的声音**放在谱表最上端或最下端最清晰（如"向乐器内吹气而不出音高"）；
- 有音高的声音照常记在谱表上（如摘下号嘴 buzz，约略音高）；
- 十字符头成组难以辨认时（尤其带加线时），可改用**穿过符杆的十字**；
- 颤舌、泛音、复音、键击有专门记法（见下），其余技法无标准记号，须文字说明。

![特殊技法的异形符头：无音高声音置于谱表端部（原书 p.248）](/img/ch09/special-noteheads.png)

### 元音/音素改变音色（Phonemes）

- 吹奏中改变口型中的元音/音素会改变音色；将要用的元音**以方括号记在谱表下方**，如 `[i]`、`[u]`、`[oo → ah → oo]`；
- 在脚注中用演奏者熟悉的语言说明发音（如 "i: ee as in seen"）；
- 须用文字说明这些声音**只是口型、并不真的发声**。

![谱表下方的元音方括号记号（原书 p.249）](/img/ch09/phonemes.png)

### 通过乐器发声（Vocal sounds through an instrument）

- **对乐器说话/耳语**：用十字符头，文字说明"按记谱指法并同时透过乐器说话"（如 Crumb《Madrigals Book IV》例）；完全独立于乐器的说话声也用十字符头，标 `spoken`；

![Crumb：边按指法边透过长笛说话（原书 p.250）](/img/ch09/speak-through-instrument.png)

- **边奏边唱**：演唱音高可用普通符头（每次进入标 `hum`/`sing`），但**cue 小符头**最清晰；放同一谱表时用分开的符杆，易混则演唱声部放下方单独谱表；偶发的发声音也可用菱形符头（如 Berio Sequenza V）；
- 演唱音高必须按乐器**正确移调**；八度移调乐器按实音书写；
- **唱 + 奏产生复音**：铜管上产生复音的唯一方法就是边奏一个音边唱另一个音，两频率相互作用产生额外音/音色；

![唱上方音产生复音（原书 p.251）](/img/ch09/sing-play-multiphonic.png)

## 9.2 移调（Transposition）

- 演奏材料中，木管铜管分谱必须按乐器正确移调；分谱中的提示声部（cues）也要移调到演奏乐器的调；
- 总谱可移调记谱，也可实音记谱（须标注）。

### 移调与调号（Transposition and key signatures）

- 调性音乐中，每个移调乐器用**各自移调后的调号**（如实音 C 大调时，B♭ 单簧管用 D 大调、A 单簧管用无升降）；
- 无明确调中心的音乐，实音版无调号则移谱也不加调号；
- **圆号和小号通常完全不用调号**（圆号演奏者尤其不习惯读调号）。

![典型木管编制的移调调号表（原书 p.252）](/img/ch09/transposed-key-signatures.png)

### 等音转换（Enharmonic conversions）

- 远离 C 大调的调，应等音转换为**升降号最少的调号**：如实音 F♯ 大调给 B♭ 乐器应转为 A♭ 而非 G♯ 大调；
- 等音两调号数相同时（如 F♯/G♭）：升调乐器（G、A 调等）给升号调，降调乐器（F、B♭ 调等）给降号调；
- 移谱中与调号矛盾的临时记号多于吻合时，考虑**不写调号**，临时记号随音出现；
- 无调号音乐中直译移调会产生大量双重升/降号，应适度等音改写以减少记号；整句统一改写以避免别扭的增减音程。

### 常见移调乐器对照

| 乐器 | 谱面与实音关系 |
|------|----------------|
| Piccolo | 记谱低八度 |
| Alto Flute（in G） | 记谱高纯四度 |
| Cor Anglais（in F） | 记谱高纯五度 |
| Clarinet in B♭ | 记谱高大二度 |
| Clarinet in A | 记谱高小三度 |
| Bass Clarinet in B♭ | 高音谱号高九度（French notation） |
| Trumpet in B♭ | 记谱高大二度 |
| Horn in F | 记谱高纯五度 |
| Alto Sax in E♭ | 记谱高大六度 |
| Tenor Sax in B♭ | 记谱高大九度 |

## 9.3 木管（Woodwind）

### 谱号（Clefs）

- 长笛、双簧管、单簧管、萨克斯只用**高音谱号**；
- 低音单簧管为 B♭ 乐器写谱，高音谱号**高九度**记谱（"French notation"，与其他单簧管指法/谱号一致）；旧谱偶见高大全度的"German notation"（低音/高音谱号按音域切换），如使用须注明；
- 大管（bassoon）用低音谱号，高音区用**次中音谱号**；个别极高音区经演奏者同意可用高音谱号代替大量加线；低音圆号——**不要在次中音谱号里写低音**；
- 八度移调乐器：短笛低八度记谱；倍低音大管、低音长笛、低音双簧管、heckelphone 高八度记谱；演奏分谱无需八度移调谱号，总谱中有帮助。

![木管乐器谱号与移调总表（原书 p.254）](/img/ch09/woodwind-clefs-table.png)

- **八度移位记号（8va）只用于长笛/短笛极高音**（约四条加线以上）；其他木管音域不需要。对木管演奏者，特定音高对应特定指法，八度移位视觉上易混淆——单簧管尤其如此（超吹为十二度而非八度，各八度指法不同）。

### 键颤音（Key trills / Timbre trills）

- 同一音高的**两种不同指法**交替颤音；标 `key trill` 或 `alternative fingering`，并写出颤音音以表明不是常规上方邻音颤音；
- **双颤音**：同一音高有两个键时（双簧管某些音），左右手指法交替可使颤音速度加倍，记**两条 trill 线**，最好注明交替哪些键。

### 泛音（Harmonics）

- 泛音是**不改变指法、超吹基础音**得到的上分音；音色透明、共鸣较少、不如常规指法稳定；
- 记法：**实音上方小圆圈**（○）；单簧管、大管用特殊指法做出的"泛音质感"音用同样记法；
- 每个泛音音符都带圈；其后同音高的非泛音音符标 `non arm.` / `ord.` / `norm.` / `nat.`（可简写 `n`）；

![泛音小圆圈记法与取消记号（原书 p.256）](/img/ch09/harmonics-notation.png)

- 长笛可用同一基础音的不同泛音做音色对比：交替不同泛音时，把**基础音（按指音）记为菱形符头**放在实音下方；长笛普通八度泛音不需要此记法，用常规小圈即可；
- 双簧管双泛音需特殊指法，记**两个小圈**在和弦上方。

![长笛：菱形符头标示基础音（原书 p.257）](/img/ch09/flute-harmonics-fundamental.png)

### 复音（Multiphonics）

- 产生方式：对单音指法过吹/欠吹，或用特殊指法；结果是两个以上音高同时被感知、音质不等的复杂振动；
- 复音常包含**难以记谱甚至难以量化的音色与音高**，某些指法在不同演奏者/乐器上结果也不同——**用文字描述所需声音类型往往比硬性规定和弦更有用**；
- **非特定复音**：只需标明要产生复音并给出大致音区（或需要控制时的音域两端），用十字或菱形符头（二分/全音符菱形更易读）；

![非特定复音：异形符头标示音区（原书 p.257）](/img/ch09/multiphonics-approximate.png)

- **基于基础音或须包含特定音的复音**：用普通符头，配文字指示，或反复出现时在**符杆上穿一个 M**（首次出现时定义）；
- **音高明确的复音**可写成和弦，依赖特殊指法时应同时给出指法（双簧类复音都必须给）。

![符杆穿 M 的复音简写（原书 p.258）](/img/ch09/multiphonics-m-stem.png)

### 指法（Fingering）

- 复音与微分音宜附指法；对比音色的替代指法最好留给演奏者（取决于乐器、演奏者、哨片和口型）；
- 指法用按键/音孔图表示，标准符号放在相关音符正上/下方：`○` 开、`●` 闭、`◐` 半开；
- 长笛横向排列最实用，其他乐器纵向；
- 反复使用的指法（如复音指法）在**前言列出指法表并编号**，数字以独特方式加框，区别于排练记号。

### 音色（Tone qualities）

- 偶发的音色变化直接用文字说明最清楚；可用对比符头区分，如长笛常用**空心菱形**定义 'breathy' 音色（须文字定义，与泛音区分）；
- Berio（Sequenza XII）用小圈直接放在相关音符上方表示不同音色（亮/暗/中间），非常经济；
- 音色与音质的平衡以文字说明最清晰。

### 键击（Key slaps）

- 键击最常见于长笛；加强吹奏音的键击：谱表上方加 `+` 或 `x` 记号（无需解释）；
- **不吹气的键击**：用十字符头记在按指音高处，须在乐曲开始或首次出现处定义"不向乐器内吹气发声"；

![不吹气的键击用十字符头（原书 p.260）](/img/ch09/key-slap.png)

- 舌头堵住吹口的键击实际音高低约大七度：记按指音高并文字说明。

## 9.4 铜管（Brass）

### 谱号、移调与调号

- **小号**：只用高音谱号；用什么调的琴是演奏者个人选择，小号分谱常直接写 C 调；极低音（pedal notes）仍用高音谱号，加线难读时用 `8va bassa`；
- **圆号**：分谱写 F 调并标注 `Horn in F`（演奏者习惯读各调旧谱）；音域大部分用高音谱号（加线到下加一线 C），低于此音用低音谱号——旧谱低音谱号低四度记谱，现行规范是**高五度记谱**（全曲移调方向一致，也避免下方加线）；因两种并存，应在首次低音谱号进入处注明实际音高关系；
- **Wagner 大号**：音域近似圆号，以高音谱号为主，低音用低音谱号；历史移调混乱，现代多按 F 圆号方式记谱；
- **长号与大号**：次中音长号用次中音+低音谱号（高音不用高音谱号）；中音长号用中音谱号（pedal notes 用低音谱号）；低音长号和大号只用低音谱号；大管式"低音写在次中音谱号"的错误要避免；大号最低音用加线而非八度记号；
- **调号**：长号、大号有调号；**小号、圆号通常不用**；
- 铜管乐队（brass band）中 B♭/E♭ 大号等移入高音谱号记谱。

### 弱音器（Mutes）

- 使用 `con sord.` 或 `mute`，取消用 `senza sordi` 或 `open`（意 `aperto`）；
- 未指明种类时默认 **straight mute**；换弱音器的指示要尽早提前给出，原弱音器无需再写"移除"；
- **圆号上 `+` 号专用于手堵音**；小号/长号上 `+` 表示手盖住钟口（配 plunger 或 harmon 弱音器）。

#### 圆号手堵音（Horn hand-stopping）

- 每个堵音上方加 `+`，下一个开放音用**音符上的圆圈**表示（不写 open，那意味着移除弱音器）；短段落可用方括号延展；
- 连音线上也宜每个音加 `+`，至少在换行后作提醒；

![圆号手堵音 + 与开放音圆圈（原书 p.263）](/img/ch09/horn-hand-stopping.png)

- 完全插手入钟口：超吹时产生 sizzle 效果，标 `cuivré` 或 `brassy`；
- 手略入钟口弯曲空气柱：闷音效果（hand horn 式堵音），有时记为 `ε`（half-stopped）。

#### Harmon 与 Plunger 弱音器

- 两者都以 "wa-wa" 音色为特征：plunger（或徒手）靠盖住/揭开钟口，harmon 靠手盖住/揭开 stem（管嘴）；
- `+` = 盖住，`o` = 揭开；`o+) (+o` 渐盖渐开，`o+ +o` 突盖突开，`O+` 盖/开颤音；
- harmon 的 stem 有全推入（默认）、全拉出、半入、完全取下几档，未说明即全推入；
- 手位/弱音器位置变化的节奏：可用连音线音符值记出，复杂时在**谱表上方单写一行节奏**配 +/o 记号。

![harmon/plunger 弱音器的 +/o 手位记号与上方节奏线（原书 p.264）](/img/ch09/harmon-plunger-signs.png)

### 技法（Techniques）

#### 活塞颤音（Valve tremolos）

- 同一音高两种指法间的颤音记作 tremolo，加 `valve trem.` 以免与颤舌混淆；
- 长号上以**罗马数字**在谱表上方标把位交替（如 `II↔V`），可注明"按住音高移动滑管"。

![活塞颤音与长号把位交替（原书 p.265）](/img/ch09/valve-tremolo-slide.png)

#### 滑音（Glissandos）

- 长号滑管最多可滑三全音，更宽的音程需滑管+唇滑结合；有阀键乐器靠阀键+泛音滑动；
- **half-valve gliss.**：阀键只按下一半，刻意模糊中间音高——演奏者常自发使用，但标出可与其他滑音类型区分；

![half-valve gliss.（原书 p.265）](/img/ch09/half-valve-gliss.png)

- **圆号手堵滑音**：手在钟口内的动作中音区约可改变半音音高；记谱应正确分配开放/堵音音符，堵音用 `+` 标出；谱面保持 F 调移调不变；
- **泛音（lip）滑音**：沿泛音列滑动；需节奏定位时应把中间泛音写出来；仅当起始音看不出基础音、或滑音中途更换泛音列时，才需标基础音/把位；不计时滑音在首尾音间画 gliss. 线，加 `harm. gliss.` 或 `overtone gliss.`；
- **爵士语汇**：斜 trill 线或弧线表示 "swoop onto"（rip，通常快，长度可文字说明）与 "fall off"（从音滑落到不确定音高）。

![爵士 rip 与 fall off（原书 p.267）](/img/ch09/jazz-rip-fall.png)

#### 指定泛音列的音（Notes from a specified harmonic series）

- 要求某音作为指定基础音的上分音（而非更稳定、更接近平均律的其他泛音）时，可加文字（如 "do not correct the tuning of natural harmonics"）；
- 可用微分音记号标出与平均律的差异——这是给读谱者的，演奏者不需要；
- 长号用罗马数字标把位；**圆号应在谱表上方标出泛音列根音**，多数演奏者喜欢按实音标（如同用该调自然圆号），分谱与总谱（无论移调与否）都要标。

> 提示：
> 本章的线索是"**记谱服务于演奏者的习惯**"：
> 圆号不加调号、小号写 C 调、低音单簧管沿用 French notation——
> 都是为了让乐手读到最熟悉的谱面；
> 而特殊技法的关键不是符号本身，而是**清晰、唯一定义、配文字说明**。
