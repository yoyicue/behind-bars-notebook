# Chapter 13：古典吉他（Classical Guitar）

> 本章对应原书 pp. 373–390。原书本章不含指板谱（Tablature）内容——Gould 明确以传统五线谱记谱为古典吉他的规范。

## 13.1 总体记谱（General notation）

- 吉他用**单谱表（stave）高音谱号**记谱，**实际音高比记谱低一个八度**；此移调音域恰好落在高音谱表舒适范围内；
- 也可使用带"8"的高音谱号（octave treble clef）明确八度移调；
- 仅在声部写作极其复杂、别无他法时才使用**两个高音谱表**，以花括号（curly brace）连接。

### 技术信息的详略程度

- 出版吉他谱通常由吉他手编辑补充弦号、指法、品位等技术信息；
- **作曲者只需为特殊音色效果指定弦号**（及极个别情况下的指法），其余弦的分配由演奏者根据技术与音色自行安排。

## 13.2 弦号（String designation）

- 六根弦的基本调弦（自上而下为第 1 弦至第 6 弦）：E–B–G–D–A–E（记谱音高）。

![吉他基本调弦与弦号（原书 p.373）](/img/ch13/string-numbers-tuning.png)

- 弦号用**圆圈数字**表示，放在谱表上方或下方——取离相关音符更近的一侧；
- **虚线水平线**表示继续使用同一根弦（推荐虚线，实线留给品位与右手指法的延续线）；
- 作曲者可为特定音色指定某根弦，否则由演奏者决定；
- **空弦音高用"0"表示**，而非弦号（原书 p.374）；
- 和弦的弦号在空间允许时**垂直堆叠**写在上方；空间不足时可进入谱表内，但可读性下降。

![空弦用 0 表示；和弦弦号堆叠（原书 p.374）](/img/ch13/open-string-zero-chord-stack.png)

- 泛音记谱时弦号尤为重要（见 13.9）。

## 13.3 右手指法（Right-hand fingering）

- 仅在教学乐谱或极特殊情形（如指定特殊指法模式）下才标右手指法；
- 用西班牙/意大利语首字母（**斜体**推荐，便于与其他技术文字区分）：

| 符号 | 手指 | 词源 |
|------|------|------|
| *p* | 拇指 | pulgar / pollice |
| *i* | 食指 | indice |
| *m* | 中指 | medio |
| *a* | 无名指 | anular |

- 小指通常不参与拨弦，仅用于弗拉门戈扫弦 rasgueado；
- 指法写在音符上方或下方，尽量避开谱表；
- **水平延续线**表示同一手指连续使用（有些版本用虚线或波浪线区分不同技法）。

![右手指法 p/i/m/a 及其延续线（原书 p.374）](/img/ch13/right-hand-fingering-lines.png)

### 和弦上的右手指法

- 空间允许时指法垂直堆叠于和弦前；
- **竖括号**表示若干音用同一右手手指（通常是拇指）弹奏——因此竖括号在吉他谱中**不能**用来表示 non arpegg.（见 13.6）；
- 琶音和弦的指法写在箭头末端；箭头在上方时指法写在箭头上方。

![和弦指法堆叠与同指竖括号（原书 p.375）](/img/ch13/chord-fingering-bracket.png)

## 13.4 左手指法、品位与横按（Left-hand fingering, fret position and barre）

### 左手指法

- 阿拉伯数字 **1–4** 表示左手四指（拇指不用）；**空弦用 0**（小圆圈留给泛音记号）；
- 指法紧靠**符头（notehead）**，最好在其正前方或上方；
- 同时出现左手指法、右手指法与弦号时，**左手指法最靠近音符**。

### 同指换把

- 同一手指同弦换品位时，在两个数字之间画**细斜线**，倾斜方向与音高走向一致（必要时可穿过符杆）；
- 空间不足或为避免与有声滑音混淆时，可只在第二个数字前画短线；
- 连接**两个符头**（而非两个数字）的线表示"换指滑移"（见 13.5）。

![同指换把斜线（原书 p.376）](/img/ch13/same-finger-shift-line.png)

### 品位（Fret position）

- **罗马数字**表示左手食指所在的品位，写在谱表上方；
- 品位标记有助于良好指法习惯，且是**自然泛音记谱的必需信息**（见 13.9）。

### 横按（Barre）

- 一指（通常食指）在指定品位按住部分或全部琴弦；
- **大横按（grand barre）**：按住 4–6 根弦，记作 **C + 品位数字**（如 CVII）；
- **小横按（half barre）**：按住 3 根或更少，记作 **1/2C + 品位数字**（如 1/2CIV）；
- C 源自 capo / capotasto（弗拉门戈 movable bar 术语 cejilla）；
- 横按持续期间可用水平线（实线或虚线）提醒保持把位；
- **竖括号 L / [** 置于和弦前（先于临时记号与左手指法，琶音线则在其前），表示食指横按的弦数；竖括号配指法数字表示同一手指跨两根弦。

![横按记法 CI–CIII 与竖括号（原书 p.377）](/img/ch13/barre-notation.png)

## 13.5 左手技法（Left-hand techniques）

### 连奏弧（Slurs）

- **虚线连奏弧（dotted slur）**表示左手做工（ligado，"左手连奏"）：只拨第一个音，其余音由左手击勾弦发声，以获得速度与连贯；
- 虚线弧习惯上**贴符头一侧**放置，即使谱表上有多个声部，以便左手指法信息（数字与弧线）集中；
- 谱表过密时也可放在符杆一端；
- **实线连奏弧**表示乐句划分，双声部写作中如有必要也可置于符头一侧。

### 滑音（Glissandos）

- **换指滑移（finger shift）**：右手只拨第一个音，左手同指滑至同弦另一音高、不出滑音声响——记为两音之间的滑音线**加一条连奏弧**（表示第二个音不另拨）；首次出现时可给两音都标指法；

![换指滑移（finger shift）：滑音线 + 连奏弧（原书 p.377）](/img/ch13/finger-shift-glissando.png)

- **有声滑音（audible glissando）**：必须写 **gliss.** 以区别于换指滑移；第二个音若要拨弦，两音之间**不加连奏弧**。

![有声滑音 gliss.（原书 p.378）](/img/ch13/audible-glissando.png)

### 弯弦（String bending）

- 按弦品位不变，拨弦后拉伸琴弦产生可闻音高弯曲（表现性或微分音）；预弯（pre-bend）后拨弦可产生微分音；
- 两种情况都应加**文字说明**（如 "bend"、"¼-tone sharp"）。

## 13.6 右手技法（Right-hand techniques）

### 和弦奏法

- 吉他手可用拇指快速扫过低音弦、其余手指同时取高音的技法，使 5–6 音和弦**不琶音化**发声；
- 需要滚动效果的和弦前加**波浪琶音线**；成串和弦用文字 **arpeggiando**；
- **不琶音**的和弦可加 non arpegg. 提醒（吉他手习惯性琶音化），或在一段琶音和弦之后使用以免被默认 simile；
- **竖括号不能用于 non arpegg.**——它在吉他谱中表示同指弹奏（见 13.3）；
- 琶音默认**向上**（音高方向）；向下用向下箭头，其后的向上箭头表示恢复向上；
- 琶音速度用文字说明：arpegg. lento / arpegg. rapido 等。

![琶音方向与速度标记（原书 p.379）](/img/ch13/arpegg-direction-speed.png)

### 扫弦（Strumming）

- **箭头**表示整个和弦扫弦；多于偶尔使用时，箭头统一放在谱表**上方**；
- 密集织体（高度半音化或复杂节奏）中，重复和弦可自第二个起**只写符杆**省略符头，仅在和弦变化时恢复符头。

![扫弦箭头置于谱表上方（原书 p.379）](/img/ch13/strumming-arrows.png)

### Rasgueado（拨击奏法）

- 弗拉门戈技法：用指甲背面扫弦，需文字指示 **rasgueado**（缩写 rasg.）；
- 范围可用虚线标示，或随后用 ord. / nat. / norm. 取消。

### 同音高的两根弦

- 交替弹奏两根同音高的弦时，每个空弦音记 **0**（不用弓弦乐器的分符杆惯例）；
- 两弦同时发声记两个符头，并注明空弦。

### 震音与颤音（Tremolos and trills）

- 单音震音：先完整记出节奏表示**有量震音**，用震音符号表示**无量震音**；用一根弦，除非额外符头表明两三根弦；特殊指法（如 pami、quasi mandolino）写在音符上方；
- 双音颤音/震音有两种奏法：
  1. **ligado**：右手拨起始音，左手交替击勾——用两音（或两组指法）之间的**虚线连奏弧**表示；
  2. **跨弦颤音**：左手按住相邻两弦的音，右手以指定指法组合快速交替——需同时标**右手指法与弦号**，且两音之间**不加连奏弧**。

![双音颤音/震音的两种记法（原书 p.381）](/img/ch13/trills-two-note-tremolo.png)

## 13.7 弦上位置与音色技法（Area of string and timbral techniques）

### 右手位置（谱表上方文字指示）

| 指示 | 技法 |
|------|------|
| sul pont.（ponticello） | 靠近琴码 |
| sul tasto | 琴品上方 |
| flautando | 八度节点处（纯木质感，非泛音；亦称 clarinet tone） |

- 用 ord. / nat. / harm. 取消，或用虚线标明持续范围。

### 音色技法

- 默认用手指弹奏；需拨片音色时写 **with plectrum**；最好描述目标音色（percussive、brilliant、metallico 等）而不过度规定技法，回到正常奏法用 with fingers 或 ord. / nat. / harm.；
- **polpastrello**：只用手指（通常拇指）的肉垫触弦；
- **pizzicato**（法语 sons étouffés，"闷音"）：刻意闷住琴声；用 ord. / nat. / harm. 取消，或用水平线标示持续；

![pizz. 及其持续线（原书 p.382）](/img/ch13/pizz-lines.png)

- **snap pizzicato**：弦回弹击打指板，借用弓弦乐器的 Bartók pizzicato 符号；
- **tambora / tamburo**：用拇指侧面敲击琴码旁的琴弦（"军鼓"效果），后跟虚线标示持续；
- **golpe**：弗拉门戈技法，敲击/弹击琴体——节奏用**叉形符头（crossed noteheads）**记在谱表外侧，加文字 golpe；需指定敲击部位/方式时给文字说明或图示。

![golpe：叉形符头记敲击节奏（原书 p.382）](/img/ch13/golpe.png)

## 13.8 延音与制音（Sustaining and damping）

- 需要特定音继续振动（laissez vibrer）时，**写足音符时值**——这同时提醒演奏者按住不放；
- 精确的时值记谱正好制衡吉他弦自然延续的倾向：演奏者必须按休止符制音；
- 时值记谱累赘时，可在音符后用**开放连音线（open tie）**；整段不制音时给总指示 l.v. sempre；
- **制音符号**（竖琴记谱中的 damping 符号）置于谱表上方，专门用来**撤销 l.v. sempre**；其余制音由休止符执行；
- 个别需制音的音或和弦可用断奏点（staccato dots）或文字 secco。

![制音符号与 l.v.（原书 p.383）](/img/ch13/damping-symbol.png)

## 13.9 泛音（Harmonics）

- 吉他可发**自然泛音**（左手轻触空弦节点，右手拨弦）与**人工泛音**（左手按弦形成基础音，右手食指触更高节点并用拇指等拨弦）；
- 泛音记谱**尚未标准化，必须注明所用记谱法的音高含义**；且由于吉他音乐整体低八度发声，泛音（包括括号内的实际音高）都应相对**记谱音高**而非音乐会音高表述。

### 记谱方案（原书 p.384–385）

1. **全部用菱形符头**写在发声音高处，不区分自然/人工——留给演奏者自行选择实现方式；
2. **区分符头**：如 Carter 用普通符头+小圆圈记自然泛音、菱形记人工泛音（Walton 则相反）；
3. **菱形写在按弦品位（fingered pitch）**：自然泛音用黑菱形（四分音符及更短），人工泛音用空心菱形；八度人工泛音把按弦音记作普通符头置于菱形下方；除八度泛音外，按弦音高与实际音高不同，**必须在括号内给出实际音高**。

![泛音统一写作菱形符头（原书 p.384）](/img/ch13/harmonics-diamond-notes.png)

![菱形写在按弦品位、括号内注实际音高（原书 p.385）](/img/ch13/harmonics-fingered-pitch.png)

**推荐记法**：统一用菱形符头（普通音符+小圆圈易与空弦 0 混淆）；如需区分自然与人工泛音再分别对待。

### 自然泛音（原书 p.386）

可用自然泛音（高于第 5 泛音者不稳定）：

| 泛音 | 高于空弦 | 触弦品位 |
|------|----------|----------|
| 第 2 泛音 | 一个八度 | XII |
| 第 3 泛音 | 八度+五度 | VII 或 XIX |
| 第 4 泛音 | 两个八度 | V 或 XII 或 XVII* |
| 第 5 泛音 | 两个八度+大三度 | IV 或 IX 或 XVI |

*原书表格为 IV / IX / XVI。

![可用自然泛音总表（原书 p.386）](/img/ch13/natural-harmonics-table.png)

- 泛音写在**发声音高**处；仅用八度泛音时不需弦号，其他泛音**必须标弦号与触弦品位（罗马数字）**；混用不同自然泛音时，八度泛音也标上弦号更清楚；
- 因按弦音高与发声音高不同，须说明书写音高（如"自然泛音记于发声音高，即比音乐会音高高八度，与吉他声部其余部分一致"）。

![八度泛音：按弦音 / 泛音 / 实际音高的关系（原书 p.386）](/img/ch13/octave-harmonic-pitches.png)

### 人工泛音（原书 pp.387–388）

- **八度人工泛音**：任何音都可升高八度作为人工泛音；推荐记法是在**按弦音高处写菱形符头**（左手按弦位置），并注明"人工泛音记于按弦音高、实际高八度"；
- 标注 **art. / art. harm.** 区别于自然泛音（随后回到自然泛音可标 nat.）；art. harm. 8va 之类的八度标记是多余的——八度泛音是默认；
- 按弦音需要加线（ledger lines）时照常使用，**不要用八度记号**（易与 art. harm. 8va 标注混淆）；

![人工八度泛音推荐记法（原书 p.387）](/img/ch13/artificial-octave-harmonic.png)

- **其他人工泛音**：右手可在按弦音上方小三/大三/四度/五度处触弦，结果音程与弓弦乐器相同，记法一致——普通符头记按弦音，空心菱形记节点（右手位置），括号内给出实际音高；

![其他人工泛音（三、四、五度）（原书 p.388）](/img/ch13/other-artificial-harmonics.png)

- 泛音与普通音结合：自然泛音可同符杆（stem）结合普通音；但一律用**分开的符杆**更清楚（人工泛音必须分符杆），否则和弦会被误认为人工泛音的指法。

![泛音与普通音结合（nat. / art. harm.）（原书 p.388）](/img/ch13/harmonics-with-ordinary-notes.png)

## 13.10 特殊调弦（Scordatura）

- 重调一根或多根弦在吉他音乐中常见，多为获得特定自然泛音或改变整体共鸣；
- 调弦变化写在**第一谱表上方**；弦一律记**发声音高**；
- 只有多次改变调弦时，才改为按指音高记谱并移调声部（此时必须精确标明弦，确保得到所需音高）；
- 微分音调弦：只要 unconventional tuning 已注明且该弦始终有标签，不必再写结果微分音。

![微分音调弦：tune ⑤ to G ¼-tone sharp（原书 p.389）](/img/ch13/scordatura-microtone.png)
